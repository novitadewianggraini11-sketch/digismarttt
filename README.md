
# DIGISMART

### Cerdas dan Aman di Dunia Digital

## Deskripsi
DIGISMART merupakan website edukasi untuk meningkatkan
literasi digital masyarakat.

Website ini memberikan pembelajaran mengenai penggunaan
teknologi secara cerdas, aman, dan bertanggung jawab.

## Fitur Website

- Login pengguna
- Registrasi pengguna
- Dashboard
- Materi literasi digital
- Edukasi anti-hoaks
- Keamanan digital
- Literasi AI
- Jejak digital
- Kuis interaktif
- Sistem penilaian

## Teknologi

- HTML
- CSS
- JavaScript
- LocalStorage
- SessionStorage

## Cara Menjalankan

1. Instal Visual Studio Code.
2. Buat folder DIGISMART.
3. Buat seluruh file sesuai struktur folder.
4. Masukkan kode ke setiap file.
5. Instal ekstensi Live Server.
6. Klik kanan index.html.
7. Pilih Open with Live Server.

## Catatan
Website ini merupakan prototipe frontend.
Untuk penggunaan publik diperlukan backend,
database, dan autentikasi yang aman.

## Tujuan
Meningkatkan kesadaran dan pengetahuan masyarakat
dalam menggunakan teknologi digital.
